# 📄 Sample Candidates for Instant Demo Testing

This folder contains realistic, pre-formatted candidate profile samples designed for quick evaluation in **TalentRank AI**.

### How to Use for Quick Demo Testing:
1. Open [`jane-doe-senior-nextjs.txt`](jane-doe-senior-nextjs.txt) or [`alex-chen-ai-engineer.txt`](alex-chen-ai-engineer.txt).
2. Copy the entire text content.
3. In TalentRank AI (`http://localhost:3000/dashboard`), click **"Import Candidate"**.
4. On the **Paste Text** tab, paste the copied text into the text area.
5. Click **"Evaluate Profile"** $\rightarrow$ Gemini will extract qualifications, evaluate against the active role criteria, and rank the candidate on your leaderboard in ~2 seconds!
